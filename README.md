# Product Card

A small HTML & CSS homework project for **Women in AI**: a product card for a "setting spray" with a "new" badge, a star rating, the price and an "add to cart" button.

## Features

- Product image added as a CSS background
- Animated "new" badge
- Hover effect on the call-to-action button
- Plain HTML and CSS, with no frameworks or build step

## Project structure

```
homework-card/
├── index.html        # Card markup
├── assets/
│   └── hydraring.jpeg  # Product image
└── styles/
    ├── reset.css     # CSS reset
    └── style.css     # Card styles and animations
```

## Getting started

Open `index.html` in any browser. Nothing to install.
